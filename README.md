## ApexPlanet Software Pvt. Ltd. — Data Analytics Internship

Welcome to my **Data Analytics Internship Portfolio** at **ApexPlanet Software Pvt. Ltd.**

This repository serves as a centralized portfolio showcasing my learning journey, analytical projects, business insights, dashboards, statistical analysis, and professional development throughout the internship.

---

## 📌 Internship Overview

During this internship, I worked through a structured series of Data Analytics projects covering the complete analytics lifecycle:

**Data Cleaning → Exploratory Data Analysis → SQL Analysis → Business Intelligence → Interactive Dashboarding → Data Storytelling → Statistical Validation → Portfolio Development**

The internship provided practical exposure to analyzing business data, extracting meaningful insights, building dashboards, and communicating analytical findings.

---

## 🎯 Internship Objectives

- Develop practical Data Analytics skills
- Work with real-world style business datasets
- Perform data cleaning and preprocessing
- Conduct Exploratory Data Analysis (EDA)
- Use SQL to answer business questions
- Build interactive dashboards
- Perform deep-dive business analysis
- Apply statistical validation techniques
- Communicate insights through data storytelling
- Build a professional Data Analytics portfolio
